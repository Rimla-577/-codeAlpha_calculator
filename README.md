# Calculator

A simple, responsive calculator built using HTML, CSS, and JavaScript.

## Features

- All basic arithmetic operations: addition, subtraction, multiplication, division, and percentage
- Real-time result preview while typing
- Clear (C) and Delete (DEL) buttons
- Error handling for invalid input and division by zero
- Keyboard support (numbers, operators, Enter, Backspace, Escape)
- Glassmorphism-style responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Use

1. Clone or download this repository
2. Open `index.html` in your browser
3. Start calculating!
